InkAsk 목업 v3 — 실물을 보고 다시 그림

앱스토어에서 Flexcil·GoodNotes·Notability의 실제 스크린샷을 내려받아 확인한 뒤, 관찰된 문법만으로 다시 그렸다. v2의 코랄·크림·히어로 필은 실물 어디에도 없던 내 창작이라 폐기.

Flexcil 주석 화면에서 관찰
  • 크롬은 순백, 아이콘은 작은 모노크롬 — 채도는 문서 제목(파랑)에만
  • 페이지가 화면을 거의 다 채움 (회색 여백 거터 없음)
  • 펜 도구는 상단 스트립, 굵기 숫자가 아이콘에 표기
GoodNotes AI 화면에서 관찰
  • AI 기능 = ✨ 스파클 아이콘, 선택 도구 활성화는 연파랑 배경 칩
  • "Ask" 결과는 바텀 시트: 흰 시트 + 라운드 보더 제안 칩 + 질문 입력
  • 브랜드 네이비+크림은 마케팅 배경이고, UI 크롬 자체는 밝고 절제됨

필기 화면 — 흰 크롬, 페이지 풀블리드

Flexcil처럼 페이지가 곧 배경. 크롬 한 줄에 작은 모노크롬 아이콘, 문서명만 파랑. Ask는 ✨ 하나.
